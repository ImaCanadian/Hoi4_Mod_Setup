# Hoi4_Mod_Setup

This works on Linux, Windows, MacOS and freeBSD.

Setups up your Hoi4 mod by creating all the major folders that one would most likely need when creating a mod, 
although most may not be needed for a simple mod, all is readily prepared for you. 

(Additional versions or a better way of running this whole operation, should be made in the future and at least for different sized mods.)

# Usage

First start off by entering into your console (Your OS's shell) or placing the .sh file into your given mod folder (the folder that holds your 'descriptor.mod' file. )

Second and last, is to launch the .sh file by any means possible and let the code do its thing.

Any preexisting folders will not be replaced by this script, and hopefully the .txt files wont be override other files. Although it is a good idea to backup your files just in case (a.k.a. remember to backup your files!)

Now you should have a fully filled mod folder compacted with the major folders that most large-scale mods would need. You can always delete the ones unwanted.

# Specialty's

This script also comes along with multiple .txt files that contain tons of important documentation that someone who is learning the basics or in needing of a refresher can use to there advantage.

All the .txt files will also be a helper in guiding and reminding on where to start, where to locate files from say vanilla Hoi4 and to maybe have premade .txt files for any future operations! 
(This also helps for if a certain code editor messes you up by not having the folder system be clear.)
